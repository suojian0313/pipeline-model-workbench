## Spec：需求一致性

核心功能在代码层面落实：原始 b3dm/tileset 加载，业务对象与几何 ID 映射，树/画布双向选择，父分组范围定位，EP3D 属性展示，日期保存/清空及数据库刷新，Node/Python 切换，选中优先于完成状态、完成状态包含后台提供的相邻元件。局部 ENU 仅用于显示，显式 `Axis.Z` 对齐附件轴向，没有修改附件或宣称真实地理位置。

本地应用与云部署准备的范围符合用户选择。独立云 Compose 使用必填连接串，不虚构已连接云数据库；两后端通过同一个 PostgreSQL 保持持久化状态。审查不将此前只交付后端时的历史文档当成本轮最终说明。

首次审查发现的自动验收覆盖缺口已在代码复核中关闭：性能分别采样 orbit/pan/zoom；读取 503 后解除拦截并重试；篡改出站日期为 `2026-02-30` 后由真实后端返回 422，验证日期未变，再恢复正常请求并保存；页面刷新后再次切换 Python，通过 UI 清空日期并比较两后端进度；相机移动/LOD 恢复后复查真实画布颜色。日期用例使用 finally 恢复原日期。最终执行结果单独记录，补齐测试代码不等同于测试已经通过。

## Quality：代码与运行质量

未发现 P1 阻塞问题。API 边界检查拒绝畸形成功响应，分页完整读取；整批请求的 AbortController/revision 防止后端切换后的旧响应覆盖新数据。日期保存捕获目标对象，切换对象不显示前一个对象的保存结果；保存已成功但刷新失败时给出准确提示。Cesium 生命周期有异步加载版本检查、销毁检查、事件解除、计时器/ResizeObserver 清理及瓦片卸载处理。

已关闭 P2：`PipelineViewer.emitMetrics()` 原先将缓存的旧 LOD/画外瓦片计入可见高亮数量。修复新增 `visibleContents`，每次 preRender 清空、tileVisible 记录，仅对最后实际渲染帧的内容统计；卸载、重新加载与销毁均清理集合。缓存仍负责样式重放。该指标统计可见瓦片中的 feature，并非逐像素遮挡查询，因此真实颜色另由画布像素验证。

主代理视觉回归发现 Cesium 默认 HIGHLIGHT 将状态色与原材质色相乘；已复核 `colorBlendMode = REPLACE`，并在本地 Cesium 源码确认默认白色 feature 不受替换模式影响，恢复原色的语义成立。进一步排查确认部分薄焊口被法兰遮挡，替换颜色无法令被遮挡表面可见，因此新增真实 bounds 的黄色选择轮廓。`setSelectionBounds()` 将同一工程坐标中的八个角点通过同一 modelMatrix 转换，以直线 polyline 连成包围框，depthFailMaterial 只让选择轮廓透过遮挡；没有替换、新造或移动源几何。选择变化先移除旧轮廓，空选择清除，Viewer 销毁统一释放实体；Vue 包装层同步单选/分组选中范围。

新增黄/绿画布像素断言排除画布四周 80 像素，避免边缘工具栏、图例或 logo 冒充模型着色。黄色断言证明选择位置轮廓可见，不证明每个所选 feature 的表面都有可见像素；绿色断言检查实际完成几何着色。README、逐题验收和三维前端导读均明确记录遮挡边界，未把轮廓描述成新造焊口表面。主代理先观察到黄色像素为 0 的失败回归，再完成定位提示与生产复测，证据链成立。

两个低优先级问题均已关闭：`compose.yaml` 的 db 已使用 `restart: unless-stopped`；启动脚本从 `docker compose config --format json` 获取实际 published 端口，不再固定打印 8088。默认生产入口为 `http://127.0.0.1:8088`。
