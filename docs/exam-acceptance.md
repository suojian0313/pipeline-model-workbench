## 实际性能与适用范围

生产 Nginx + 两版 API + PostgreSQL 均在 Docker 中，浏览器为本机 Chromium，Windows，视口 1540×960，默认硬件加速。WebGL 返回：`ANGLE (NVIDIA, NVIDIA GeForce RTX 4060 Ti, Direct3D11)`。冷加载使用全新浏览器上下文，无该上下文的 HTTP 缓存；不是模拟冷磁盘或断网下载依赖。

| 手势 | 平均 FPS | P95 实际帧间隔 | 标准 |
|---|---:|---:|---|
| 旋转 orbit | 133.69 | 6.60 ms | ≥20 FPS，P95 ≤50ms |
| 平移 pan | 164.89 | 7.00 ms | ≥20 FPS，P95 ≤50ms |
| 缩放 zoom | 130.66 | 13.30 ms | ≥20 FPS，P95 ≤50ms |

连续 90 次输入在浏览器内部由 requestAnimationFrame 驱动，统计来自 Cesium postRender，包含实际渲染间隔，不把输入事件数量当成帧数。静止采用按需渲染，不采样空闲停顿。交互提高屏幕空间误差（16→512），停止约450ms后恢复16；近处仍可能需要细层，不保证每次都落到粗层。

这些是本机结果，不能保证其他电脑的 GPU、驱动、分辨率与网络同样表现。此前强制 SwiftShader 软件渲染约 1.9 FPS，不满足 20 FPS；正式验收应确认浏览器硬件加速并在目标设备重测。
